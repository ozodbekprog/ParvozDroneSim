## Prompt 1

Use case: ui-mockup. Generate a high-fidelity raster design concept board for the existing desktop browser FPV drone simulator Drone Liftoff. This is a design proposal, not a screenshot of implemented software. Landscape high resolution. Show exactly FOUR equally sized 16:9 game screens in a neat 2-by-2 grid with small gutters: top left Pilot profile, top right Settings, bottom left Create room, bottom right Flight menu. Each screen is a coherent polished UI over the same subdued, soft-focus low-poly industrial drone flight map; preserve the browser game's restrained matte navy/charcoal, ivory text, amber primary actions, cyan numeric information. No game logo bar on secondary menus. No browser chrome, devices, watermarks, gratuitous sci-fi decoration, paragraphs of help, scrollbars, huge empty areas, financial shop, or new game features. Same typography, corner radius, button sizing, thin line icons, back control and spacing across all four screens. Large clear text, exact short English UI labels. Condensed strong headings plus clean sans-serif body. Use fictional sample pilot "Pilot 01", "Level 1", "1000 Rating", "60 cr". Pilot profile: avatar/identity and XP progress, records/achievements/rankings/account tab navigation, active Records with 2 compact sample course records and a separate ranking panel; account and recovery controls belong in Account tab, not verbose warnings over player identity. Settings: compact "Controls", "Camera", "Graphics" navigation, no three enormous icon tiles; show Controls selected with "Radio", device selector, "Calibrate", a minimal live input diagram and "Flight mode" selector. Create room: visibility segmented "Public" / "Private", "Pilots" selection with 8 selected, compact mode options "Race", "Time trial", "Freestyle", "Championship", "Back" and prominent "Select map" forward action; no disconnected small legacy modal, no instructional copy. Flight menu: compact "Paused" SOLO badge, "Kestrel 5" and "Acro", strongest primary action "Continue", quieter "Restart", "Save replay", "Settings", clearly separate "Exit flight". This is a solo pause; no falsely paused multiplayer display. Every screen's action hierarchy must be immediately obvious. Do not reproduce the current poorly composed profile, settings, host dialog or pause.
BOARD 01 — CONTINUITY. Title outside screen grid: "01 / Shared panels". Closest to the game's admired Career and Weekly Challenge: well-balanced two-column navy panels, 14px restrained rounded corners, same opaque amber buttons, cyan small numbers, compact header with filled Back button. Profile spans a balanced identity column and record/ranking column. Settings uses a narrow category rail on the left and broad precise settings pane on right. Create room uses a large centered split panel with settings left and a compact session summary right, forward action in a clear footer. Pause uses a centered small two-column card, context left, five organized actions right. Panels sit centrally, use around 70-80% of each screen, no sprawling overlay. Maintain harmonious familiar branded warmth and strong readability.
