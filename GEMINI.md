## Где работать

- `src/` — клиент, интерфейс, рендеринг и загрузка ресурсов.
- `shared/` — физика, протокол и общие определения; `server/` — сервер и аккаунты.
- `content/` — канонические ресурсы, редактируемые `.blend`, описания и лицензии.
- `editor/`, `tools/`, `test/` — редактор, инструменты и действующие проверки.
- `deploy/` — развёртывание; `docs/` — инструкции и результаты проверок.

Нужны Node.js 24+ и Git LFS. В этой рабочей папке зависимости уже установлены.
Для нового клона: `git lfs pull`, затем `npm ci`.

```powershell
npm run content:check
npm run build
npm start
```

Сборка сама выполняет `content:sync`. Для полной проверки кода есть `npm test`;
при ограниченной памяти запускай связанные группы файлов отдельно, как описано
в документации. Для обычной разработки повторный импорт Liftoff не требуется.

## Текущее состояние и ограничения

Игра опубликована: https://parvoz-drone-sim.duckdns.org/ . Локальный интерфейс
содержит неопубликованные изменения и не является публичной UI-базой.
Отклонённые макеты не одобрены; сначала небольшое превью от полного публичного
интерфейса, затем отдельное разрешение пользователя на выпуск.
См. `docs/UI-ITERATION-RULES-20261029.md`.

Последняя записанная публикация — `20261026-collision-01`; её финальная
браузерная проверка и переключение `current` остаются незавершёнными.
Это запись состояния, а не свежая проверка сервера. Перед сетевой работой читай
`docs/ORACLE-DEPLOYMENT.md`, `docs/FREE-HOSTING.md` и `docs/WEB-BETA.md`.
Не меняй сервер, аккаунты или лимит 20 игроков во время обычной локальной работы.

Уборка 31 октября описана в `docs/PROJECT-CLEANUP-20261031.md`. Основные кэши
импорта и исходники сохранены; удалённые старые экспорты не нужно создавать
заново. Ironworks остаётся архивом для ручного восстановления. Разрешение на
тест импортированных ресурсов не подтверждает лицензию на распространение.
