# Original generated art

The game uses built-in image generation for the following original raster assets. These are starting textures and key art; developers can replace them with authored assets without changing the content schema.

| File | Generation prompt |
| --- | --- |
| `public/art/hero-hangar.png` | Photorealistic cinematic key art for an FPV drone racing game: a detailed racing quadcopter on the right side inside a contemporary aircraft hangar, dramatic warm sunlight, dark open negative space on the left for UI, premium photography, no text, no logos. |
| `public/art/concrete-floor.png` | Seamless photorealistic overhead texture of worn aircraft hangar concrete, subtle cracks, aggregate, oil patina and tire wear, evenly lit, no objects, no text. |
| `public/art/forest-floor.png` | Seamless photorealistic overhead texture of damp forest ground with moss, dark soil, pine needles and sparse small stones, evenly lit, no objects, no text. |
| `public/art/canyon-floor.png` | Seamless photorealistic overhead texture of sunbaked red canyon dirt and sandstone dust with fine gravel and subtle natural erosion, evenly lit, no objects, no text. |

Generation mode: built-in `imagegen` tool. All four images are stored locally in this project and served by the game.
