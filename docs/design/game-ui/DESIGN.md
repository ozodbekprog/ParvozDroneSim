# Игровая композиция интерфейса

## Основа

Главное меню показывает настоящую выбранную 3D-карту. Камера плавно смещается, учитывает границы карты и отключает движение при системной настройке reduced motion. Статичная сгенерированная панорама больше не используется в интерфейсе или сборке.

Общие материалы: графитовые панели, мягкие скругления, оранжевые основные действия, голубые технические данные. DM Sans отвечает за элементы управления, Barlow Condensed — за заголовки, моноширинные цифры — за настройку полётного контроллера. Профиль находится в правом верхнем углу с отступом 20 px.

## Разные задачи — разные экраны

| Экран | Композиция |
| --- | --- |
| Main menu | Один короткий список игровых разделов слева и живая карта на остальной площади. Fly — основное действие. Weekly challenge и Replays раскрываются через More; Graphics находится в Settings. Постоянная верхняя навигация скрыта на всех экранах. |
| Flight setup | После Fly выбираются режим, карта, дрон и, при необходимости, маршрут. Основное действие запускает выбранный полёт. Возврат из Drone Selection сохраняет настройку режима и карты. |
| Drone Selection | Большая модель в центре, название/характеристики/действия справа, горизонтальные карточки фактических моделей и фильтры снизу. Камера обходит неподвижный дрон. |
| Workbench / Parts | Слева библиотека и категории деталей, в центре дрон и выбранная деталь, справа установленная сборка и реальные характеристики. Камера вращается вокруг модели и сохраняет ракурс при замене деталей. Сохранение расположено отдельно снизу. |
| Workbench / Appearance | Цвет корпуса, палитра и LED слева; живая модель в центре, сборка и характеристики справа. |
| Workbench / Tuning | Rates и level modes слева, модель и график отклика в центре, PID и throttle справа. Не относящиеся к настройке характеристики скрыты. |
| Multiplayer | Большая панель браузера комнат слева, чемпионат под ней; создание/вход по приглашению и ranked в отдельных панелях справа. |
| Settings | Общий вход в Controls, Camera и Graphics. Возврат из категории идёт в Settings, затем — в исходное меню, в том числе в паузу. |

Сохранение модификации не выбирает её для полёта. Оригиналы остаются заводскими; меняется только копия. Предупреждение о несохранённых изменениях и проверка допустимых значений сохраняются. Новые детали автоматически появляются в текущей категории Workbench после обновления каталога, без потери черновика.

## Референсы

- [Официальное руководство VelociDrone, раздел Main Menu, стр. 7](https://www.velocidrone.com/downloads/VelociDroneManual.pdf): быстрый вход в полёт, выделенные игровые режимы, недельное соревнование и сцена симулятора. Использованы принципы приоритета действий и композиции вокруг сцены.
- [Liftoff — обновление 1.6.4](https://www.liftoff-game.com/news/update-164-released): расширяемые компоненты дрона и настройка камеры в Workbench. Это ориентир для предметного интерфейса сборки FPV-дрона.

Это самостоятельный дизайн; изображения и элементы интерфейсов этих игр не перенесены в проект.

## Проверка

- `npm run build` — успешная production-сборка.
- `npm test` — 128 тестов проходят, включая камеру меню, орбиту предпросмотра, управление, уроки, Freestyle, наблюдение после финиша и сетевые сценарии.
- Личная проверка в Browser: расположение панелей на 1280×720 и DOM-границы на 1920×1080; цвет корпуса; изменение двигателя; сохранение копии без автоматического выбора; live rates и предупреждение при выходе; выбор карты; запуск, пауза и завершение полёта; форма создания комнаты и фильтры. В консоли обеих проверенных вкладок нет ошибок.
- В открытый Workbench добавлена временная деталь через `content/parts/`: карточка появилась после обновления каталога, несохранённое значение `rates.roll.rcRate = 1.11` сохранилось. Временный пакет удалён; каталог снова содержит 15 исходных деталей.
