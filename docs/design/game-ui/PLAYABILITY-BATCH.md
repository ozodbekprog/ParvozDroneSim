# Главное меню и следующая пачка игровых исправлений

Дата: 2026-10-03.

## Главное меню

На первом экране остались Fly, Multiplayer, Hangar, Career, Flight school и Settings. Weekly challenge, Replays и Graphics доступны через More. Убраны отдельные карточки карты, дрона, соревнования и выбора режима; настоящая 3D-сцена сохранена.

Fly открывает Flight setup с четырьмя режимами: Free flight, Race, Time trial и Freestyle. Режим, карта и дрон выбираются до запуска. Free flight не требует маршрута; гонки показывают Course, Freestyle — Gate layout. Возврат из ангара сохраняет выбор. Верхняя кнопка Fly на внутренних экранах также открывает настройку полёта. Короткие окна поддерживают прокрутку меню.

## Исправления

| Проблема | Исправление |
| --- | --- |
| Клавиатурный газ и нажатые кнопки сохранялись после потери фокуса | Сброс при blur, смене видимости и устройства; вне фокуса отправляются нулевые команды. Пауза, продолжение, reset, restart, завершение и выход также сбрасывают клавиатуру. |
| Выбранное радио исчезало, а управление могло продолжиться другим устройством | Отключённое явно выбранное радио даёт нейтральные команды. Solo ставится на паузу; Settings показывает отключение и позволяет выбрать Keyboard only. |
| HID без первого отчёта мог давать ненулевой газ | Отсутствующие и нечисловые оси остаются нейтральными до валидного отчёта. |
| Авария в уроке возвращала к началу маршрута и оставляла частично выполненное удержание | Пройденные шаги сохраняются; восстановление идёт за последними пройденными воротами, незавершённое удержание начинается заново. Подсвечиваются следующие нужные ворота. |
| После аварии остаток команд текущего кадра сразу двигал новый дрон | Оставшиеся команды отбрасываются; газ сбрасывается при изменении resetId. Это включает исчерпание батареи. |
| Reset Freestyle переносил незавершённый трюк и комбо | Очки сохраняются, незавершённые трюки и комбо сбрасываются. Лимит 180 секунд срабатывает даже при аварии на последнем такте. |
| Solo Freestyle не отправлял очки на сервер | Очки отправляются после завершения. Аккаунт получает личный рекорд по карте, XP, credits и достижение за 300 очков. Гости получают результат сессии без записи прогресса. Рекорды видны в Pilot profile. |
| Freestyle показывал очки, но не оставшееся время | В HUD рядом с очками появился компактный Time left. Он использует тот же таймер сессии и останавливается при паузе Solo. |
| Каждый сетевой snapshot возвращал камеру к уже финишировавшему дрону | Финишировавший собственный дрон обновляется как удалённый. Выбранный живой пилот остаётся целью; при его финише или выходе выбирается следующий доступный. Next pilot циклически переключает только продолжающих полёт. |

## Проверка

- `npm test`: 124 passed, 0 failed. Новые регрессии воспроизводили ошибки управления, уроков и Freestyle до исправлений.
- Реальный HTTP-сервер в изолированной временной базе: личный рекорд Freestyle по каждой карте, награды, достижение, гости, отклонение неверных результатов и сохранность после перезапуска. Старый контракт timed results проверен отдельно.
- Существующие тесты реальных WebSocket-сессий проходят: браузер комнат, приватность, чат, изоляция финишировавшего пилота, три тура чемпионата, ranked и weekly.
- `npm run build`: production-сборка успешна. Каталог: 12 карт, 4 дрона, 15 деталей.
- Личная проверка в Browser: главное меню, раскрытие More, четыре режима Flight setup, возврат из Drone Selection с выбранным режимом, запуск Free flight, пауза с остановкой таймера, продолжение, R/reset, Restart с новым отсчётом, Exit и Flight school.
- В production Browser выполнен полный трёхминутный Solo Freestyle гостем без манёвров: результат 0 pts, переход к результатам и Fly again с новым отсчётом. Консоль без ошибок. Результаты: [freestyle-results.jpg](screenshots/freestyle-results.jpg).
- После добавления Time left проверены его отображение и сохранение оставшегося времени при паузе/продолжении. HUD: [freestyle-hud.jpg](screenshots/freestyle-hud.jpg). Pilot profile показывает раздел FREESTYLE BESTS, для гостя — пустой список.
- Обновлённый локальный сервер запущен на `http://localhost:2567/`.

## Границы проверки

Физическое радио не подключалось; отключение и отсутствующие HID-каналы покрыты тестами. Полный урок с ручным прохождением ворот и финиш нескольких пилотов в Browser не выполнялись: восстановление урока и выбор камеры проверены регрессионными тестами. Это завершённая пачка исправлений; она не означает, что все режимы игры прошли длительный игровой прогон.
