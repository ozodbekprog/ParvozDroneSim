# Menu system and identity review — 17 October 2026

The user accepted the implemented compact charcoal Sign in/Downloads panels and
explicitly requested the same visual system throughout the remaining menus.
Source Sans 3, charcoal surfaces, warm orange primary actions, 4–5 px corners,
ordinary sentence-case labels and restrained borders define this extension.

Identity remains a separate visual choice. The user **rejected both A and B**
in `mark-options.png` (original editable SVG sketches, rendered by the adjacent
script). Do not install either mark. A second board, `mark-options-cde.png`, was
created with the built-in image_gen tool and shown in chat. The user selected E.
C is an angular front-facing drone, D a compact abstract flight mark, E a flowing
drone silhouette. `src/assets/parvoz-mark.svg` is the editable vector refinement
of E, replacing the P placeholder in Home, loading and the favicon. Its flowing
arms and open camera shape use the accepted off-white/orange palette.

## Second-board generation prompt

Create a carefully art-directed brand identity exploration board for PARVOZ, an FPV drone racing simulator. Three distinct premium original abstract logo proposals side by side on warm charcoal #181b20. Flat vector-like shapes with very precise purposeful geometry, white/offwhite and optional small muted orange #eea462 accent, no gradients, no glow, no 3D rendering, no mascot, no photorealism. Needs a memorable professional game brand, restrained but energetic, optically balanced and legible at 24 pixels. Do NOT imitate any existing drone game logo. User rejected a plain X with diamond center and a simple three-blade fan. Avoid those, generic propeller clipart, generic app tiles, four circles linked in a cross, winged esports shields. Three substantially different thoughtfully developed concepts: C: abstract low forward-facing FPV quadcopter silhouette tilted in flight, angular swept arms and a single distinct negative-space camera/visor notch, compact horizontal silhouette, no literal detail. D: elegant monolithic folded racing-frame symbol using two interlocking swept surfaces and one decisive diagonal negative-space channel suggesting upward flight; compact asymmetric silhouette balanced by weight. E: highly simplified FPV drone frame viewed obliquely from above, four arms fused into a bold continuous ribbon outline around a forward camera cutout, original distinctive silhouette avoiding a mere X. Each panel shows a large icon, a clean modern slightly wide wordmark 'PARVOZ' below, and one small 24px version in an understated menu-header context. Label concepts only 'C', 'D', 'E' in small type above. No slogans or explanatory sentences. Equal visual weight. Landscape wide board, high-quality real graphic design presentation with ample negative space.
