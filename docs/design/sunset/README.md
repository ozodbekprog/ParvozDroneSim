# Cinematic / Sunset — выбранный вариант 3

## Концепция

Панорама закатного каньона, тёплый персиковый акцент, молочный текст, полупрозрачные тёплые тёмные поверхности. Панели скруглены на 26 px, поля на 13 px, основные кнопки имеют форму капсул. Главный экран оставляет большую часть панорамы открытой.

Основной референс: [вариант 3](../variations/03-cinematic-sunset.png).

## Реализация

| Область | Изменения |
| --- | --- |
| Общая оболочка | Единая палитра, шрифт DM Sans, скругления, навигация, модальные окна, загрузка и адаптивные размеры |
| Главный экран | Панорама, выбор режима, быстрый запуск полёта, смена локации |
| Локации | Карточки реальных карт, выбор трассы, параметры ветра |
| Ангар | Drone Selection с All / Original / Modified; отдельный Workbench для копий, карточки деталей и интерактивная 3D-модель |
| Управление и настройки дрона | Общие поверхности, поля, график отклика и персиковые акценты |
| Графика | Выбор пресета капсулами, параметры качества без дублирующего селектора |
| Карьера, профиль, недельные задания | Общий стиль карточек, прогресса и результатов |
| Мультиплеер и лобби | Общий стиль комнат, готовности, участников и результатов |
| Школа и повторы | Список уроков, библиотека и управление воспроизведением |
| HUD | Компактная капсула скорости, времени и батареи; название локации, цели и пауза; высота, газ, сброс и сохранение повтора в раскрываемом меню |
| Редактор контента | Палитра и скруглённые элементы управления согласованы с игровым интерфейсом |

Основные файлы: `src/ui-design.js`, `src/sunset.css`, `src/main.js`, `editor/sunset.css`, `editor/main.js`.
