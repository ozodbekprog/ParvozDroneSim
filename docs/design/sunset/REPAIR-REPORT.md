# Исправления интерфейса и новый ангар — 3 октября 2026

## Drone Selection и Workbench

- Ангар открывается как **Drone Selection**: прокручиваемый список, фильтры **All / Original / Modified**, отдельный выбор дрона для следующего полёта.
- **Original** восстанавливаются из каталога и не редактируются. Для изменения создаётся **Modified** с именем исходной модели и номером: `Kestrel 5 Copy 1`, `Kestrel 5 Copy 2` и далее. Удалённые номера не используются повторно.
- **Workbench** открывается отдельно для копии. Детали выбираются карточками в прокручиваемой области; вкладки **Parts / Appearance / Tuning** заменяют общий набор выпадающих списков.
- Черновые правки применяются только через **Save & use**. **Discard & back** оставляет сохранённую копию прежней.
- Копия хранит собственные детали, цвет и контроллер полёта. Оригинал использует заводские параметры.
- Существующие изменённые сборки и настройки контроллера переносятся в копию при первом открытии. Копии разделены по пилотам в этом браузере и входят в экспорт локальных данных.
- Перед входом в сетевую комнату выбранная сборка передаётся серверу; контроллер выбранной копии используется в локальном и сетевом полёте.

## Воспроизведённые и исправленные ошибки

| Ошибка | Причина | Повторная проверка |
| --- | --- | --- |
| Пункты Explore не реагировали на клик | Панели с размытием перекрывали выпадающую навигацию. При замере `elementFromPoint` пять из шести кнопок попадали в панель экрана | Поднят слой верхней панели. Все шесть кнопок получают клик; Weekly, School, Replays, Career и Multiplayer открываются |
| Pause не срабатывал сразу после сохранения повтора | Уведомление перекрывало кнопку в нижнем правом углу | Уведомление пропускает указатель. При видимом уведомлении проверен клик Pause и открытие паузы |
| Свободный полёт запускался с заданием отменённого урока | При отмене загрузки сохранялись `launch.tutorial` и `launch.challenge` | Проверен путь School → урок → Cancel → Fly → Free flight. В HUD теперь Free flight, без инструкции урока |
| После отмены загрузки возникали ошибки на каждом кадре | Звук читал `battery` у `localState = null` | Добавлено отключение каналов звука при отсутствии состояния/сборки. Тест сначала воспроизвёл исключение, после исправления проходит; повторный браузерный путь без новых ошибок |
| Три старые проверки контента падали | Фиксированное число карт, старые размеры ворот/стартовая точка, игнорирование файлов mesh-коллизий | Проверки используют текущий spawn и опубликованные collision sidecar; проверяют реальные маршруты и геометрию |

## Проверка

QA-агент не использовался. Основной исполнитель сам проверил интерфейс в браузере; отдельный исполнитель реализовал хранение копий и исправление звука с тестами.

**Автоматически:** полный `npm test` прошёл **92/92** проверки, включая сетевые сценарии по настоящим сокетам. Лог: [repair-tests-final.log](repair-tests-final.log). Для запуска дочерних процессов тесты выполнялись с разрешением окружения; ошибки EPERM при запуске без этого разрешения относятся к ограничению среды.

**В браузере, 1280×720:**

- Создание Copy 1 и Copy 2, фильтры, заводские параметры оригинала.
- Изменение моторов, цвета, rates и PID; сохранение и повторное открытие после перезагрузки.
- Отмена черновика и удаление копии. Тестовые копии удалены, исходный дрон восстановлен.
- Локальный полёт, HUD, reset, pause, Controls/Graphics из паузы, продолжение и выход.
- Сохранение, просмотр, пауза/камера, переименование и удаление повтора.
- Карьера, профиль, помощь, недельное задание, школа и выбор карт.
- Приватная комната: загрузка, готовность, чат, старт, HUD, пауза и выход. Комната закрыта после проверки.
- Отмена урока → обычный полёт: без оставшегося задания и без новых ошибок консоли.

Физический радиопульт, WebHID, мобильное окно и полное прохождение каждой трассы вручную не проверялись. Покупка платных деталей на реальном аккаунте вручную не выполнялась.
