# Interface and HUD alternatives

These concepts replace the earlier graphite/lime proposal as the options for selection. The user found that proposal too dense and too angular and requested different variations before implementation.

Each image pairs a main menu with an in-flight HUD. The scenery and aircraft are concept art; production should retain real game assets and telemetry.

| Option | Direction | Composition |
| --- | --- | --- |
| [01 — Soft Graphite](01-soft-graphite.png) | Charcoal, lavender, rounded controls | Aircraft preview, three activity cards; small HUD pills at the edges |
| [02 — Air / Pearl](02-air-pearl.png) | Light pearl, sage, soft contrast | Vertical activity list, aircraft preview; frosted light HUD pills |
| [03 — Cinematic / Sunset](03-cinematic-sunset.png) | Full scenic background, cream and peach | Compact activity selector over location view; combined bottom HUD strip |
| [04 — Play / Mint](04-play-mint.png) | Soft dark surfaces, mint, large rounded previews | Location carousel and simple navigation; sparse race HUD |

Generated with the built-in image_gen tool. Exact generation prompts are in [prompts.json](prompts.json).
