# Local render resolution verification

Actual game UI from an isolated local server, 23 October 2026. This is not a
public-URL acceptance capture. The 30% shortcut sets the framebuffer to 403x226
on this viewport, while the menu stays sharp. Same viewport at 100% gives
1345x756; 50% gives 672x378. Adaptation is disabled by manual selection.
