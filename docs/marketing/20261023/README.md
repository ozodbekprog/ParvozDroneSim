## Следующие два сюжета

1. «Почему FPV-дрон падает при первом взлёте»: реальные стики и одно упражнение
   удержания высоты; новичку должно быть понятно, какую ошибку исправить.
2. «Один маршрут — три попытки»: падение, повтор, успешное прохождение. Только
   реальные кадры одного билда, без обещаний переноса навыка один в один.
