# Local Hangar and menu verification

`home-selected-drone.png`: actual local game, selected Kestrel frozen near the
home camera. `repaired-hangar.png`: actual workshop at end of scripted orbit.

The JSON captures report CPU/frame milliseconds, calls, triangles and actual
framebuffer. Use the timed-orbit pair for equal wall-clock camera paths; earlier
captures rotated per frame and are not comparable. This is a development-machine
diagnostic, not UHD 620 or sustained 60 FPS certification. See the parent
HANGAR-ACCOUNT-RACE document for measured limits and publication status.
