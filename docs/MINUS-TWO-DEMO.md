# Minus Two — локальная демоверсия, 9 октября 2026

Карта восстановлена из `D:\Programs\Liftoff` через AssetRipper Free и собрана в Blender. После удаления праздничных объектов сохранены исходная планировка и полноценная геометрия: 2960 активных объектов, 365104 треугольника в нативном исходнике, площадь примерно 156×105 м. Kestrel, его ID, модель, характеристики и flight-controller не изменены. Добавлены наша гаражная трасса с 12 воротами, короткая трасса с тремя воротами, обучение взлёту/воротам/посадке и миссия на 90 секунд. Существующие карты и контент сохранены.

Удалены праздничные иерархии (Christmas/Halloween/Easter/Valentines, снеговики, сердца, яйца, золото, радуги, конфеты); обычная обстановка гаража сохранена. Проверка до исправления: 1217 / 3561 пропавшая поверхность из 7928 проб; после сохранения геометрии: 0 на каждом уровне из 7829 проб.

После безопасного объединения копланарных граней coverage также остаётся 0 / 7829 на всех трёх уровнях. Браузерный замер у старта: **319653 треугольника, 233 draw calls, 58.5 MiB текстур**. Треугольники пока превышают бюджет 300000; это локальная исправленная версия для просмотра, а не подтверждение производительности или готовности выпуска. KTX2-пакет около 27.3 MiB. Исправленный снимок: `content/review/minus-two-demo/fixed-start-low.jpg`; показатели: `render-budget-fixed.json`.

Добавлены все пять штатных гонок Minus Two: **Turn Signals** (3 круга, 19 checkpoint), **Saro's Revenge** (3, 18), **The Underground Scene** (3, 9), **Concrete Jungle** (2, 18), **Drift Style** (3, 9). Используются существующие видимые ворота игры; декоративные конусы и ограждения самих трасс пока не перенесены.

## Открыть

- [Показ Low с ракурсами, взлётом, посадкой и осмотром трассы](http://127.0.0.1:2570/editor/minus-two-review.html?backend=webgl).
- [Обычная локальная игра](http://127.0.0.1:2590/): Fly as guest → Fly → страница 2 → Minus Two - Demo. Выбрать Free flight, Race или Time trial; для полной гонки выбрать трассу Garage Loop. Обучение находится в Flight school, миссия — в Career; гостю карьерный прогресс недоступен.

Сервер слушает loopback с отдельной базой `data/minus-two-demo-server` и лимитом 20. Oracle и база опубликованной игры не обновлялись. Локальная страница осмотра использует настоящие World renderer / physics; кнопка осмотра перемещает только камеру.

Если процессы остановлены, в двух терминалах PowerShell из корня проекта:

```powershell
$env:HOST='127.0.0.1'
$env:PORT='2590'
$env:DATA_DIR='C:\DroneLiftoffUz\data\minus-two-demo-server'
$env:MAX_MULTIPLAYER_PLAYERS='20'
npm start
```

`npm start` собирает игру и запускает редактор, если порт 2570 свободен. Дополнительный терминал редактора нужен только если он не запустился:

```powershell
npm run editor
```

- Content validation и production build прошли; существующие тесты: 169 passed, 0 failed.
- Физический старт, зависание на 1.4 м, контакт пола при посадке без повреждения и checkpoint reset прошли.
- Направления и свободные подходы всех 12 ворот проверены. Через SoloSession проверены завершение учебных шагов, timed mission и restart с контролируемыми подходами к воротам. Это не ручное прохождение всей гонки.

Старые цифры 103410 / 248 относятся к повреждённому упрощённому экспорту и больше не являются приёмкой исправления.
