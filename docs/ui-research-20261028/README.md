# Варианты UI поверх актуального кадра ангара

**Следующее исследование после замечания о пропавших изображениях дронов:**
[проверка/установка skills и MCP, три новых варианта с реальными миниатюрами](../ui-tooling-20261028/README.md).

**Новая серия после отклонения мультяшных вариантов:**
[три сдержанных направления на свежем публичном кадре](realistic/README.md).
Публичная игра восстановилась; новый фон снят именно с опубликованной версии.
Ниже сохранена история первоначального локального сравнения.

28 октября 2026, Asia/Tashkent. Продолжение исследования после отклонения
трёх изображений от 27 октября. Пользователь потребовал использовать **реальный
актуальный скриншот ангара фоном**, затем показать разные варианты UI.

Варианты сделаны как отдельные HTML/CSS-макеты. Один и тот же PNG — обычный
`<img class="backdrop">` под интерфейсом, без AI-генерации, ретуши, цветовых
фильтров, замены модели, освещения или интерьера. Он не пересоздаётся при смене
варианта. Кнопка «Показать исходный фон» скрывает только слой макета.
Это исправляет главный недостаток предыдущего сравнения: улучшенный генератором
ангар больше не влияет на выбор оформления.

## Состав и границы

- `prototype/` — отдельный локальный проект, не импортируется игрой.
- Web Awesome Core **3.14.0**, MIT: настоящие `wa-button` и `wa-details`,
  индивидуальные imports. Установка и lockfile только внутри прототипа.
- Рассчитанные характеристики показаны через read-only HTML `meter`,
  не через перетаскиваемый slider. Диапазоны шкал — иллюстративные пределы
  макета; они не являются новой нормализацией или изменением физики.
- Числа снятой текущей сборки: 595 г, 35 мс, 28.9 Вт·ч, 5.6×, около 6 мин,
  105°; рама Luma 5 frame 219 г. Пример пропеллера взят из открытой панели игры.
- Категории, вкладки и disclosure интерактивны для просмотра состояний.
  Редактор деталей, изменение камеры, полёт и сохранение в игру не подключены.
  Кнопки Save/Back сообщают, что это макет. Данные игрока не меняются.
- Source Sans 3 и существующий знак PARVOZ взяты из текущего проекта.
  Никакой новый логотип не утверждается.
- Палитра и компоновка **не выбраны пользователем**. Это материал для обсуждения.

## Запуск

Из корня репозитория:

```powershell
npm ci --prefix docs/ui-research-20261028/prototype --ignore-scripts --no-audit --no-fund
npm run dev --prefix docs/ui-research-20261028/prototype
```

Используется уже установленный Vite корневого проекта; его package.json/lockfile
не меняются. Сервер слушает только `127.0.0.1:2571`.

- `?variant=1`, `?variant=2`, `?variant=3` — выбранный вариант.
- `&capture=1` — убрать внешнюю полосу сравнения из снимка, оставив пометку макета.
- Клавиши 1/2/3 переключают варианты; Source скрывает слой UI.
- Канва макета 1920×1080 масштабируется с сохранением пропорций внутри окна.
  Это сравнение desktop-композиции; оно не доказывает, что UI уже адаптирован
  для игры, мобильных устройств или приёмочного UHD620.

## Приёмка

Метод съёмки, версия публичного клиента, размеры, возврат временных настроек
браузера и PNG-проверки записываются в `CAPTURE.md`. Источник/лицензии —
`ASSETS.md`. Статические кадры вариантов — `previews/`.

Код игры, физика, основная база и Oracle этим этапом не изменяются. После выбора
визуального направления нужен отдельный план и одобрение пользователя до
реализации в игре. Ранее отклонённые концепты сохраняются как история, но
не являются принятой арт-дирекцией.
