# Сдержанные варианты на свежем публичном ангаре

28 октября 2026, Asia/Tashkent. Пользователь отклонил предыдущие варианты как
мультяшные и потребовал актуальный кадр. Это новая серия обсуждения, а не
реализация UI игры. Цвет, компоновка и направление ещё не выбраны.

## Источник и проверка

Фон снят в Chrome с https://parvoz-drone-sim.duckdns.org/ после очистки
CacheStorage и обхода HTTP-cache/service worker. Первая загрузка получила
ERR_NAME_NOT_RESOLVED, следующая ERR_NETWORK_CHANGED. Пользователь выбрал
дождаться публичной игры вместо локального кадра. После восстановления
подключения открыты Играть → Ангар. Реальная модель Luma 5 Copy 1 и окружение
появились; подготовка закончилась. Загружен публичный index-OPei9JC_.js.

- `evidence/public-hangar-ui.png` — прямой снимок текущего публичного UI.
- `evidence/public-hangar-background.png` — та же сцена, временно скрыт только
  UI через `#app > :not(#viewport){visibility:hidden!important}`. Layout и
  параметры камеры не менялись этим стилем. Стиль удалён сразу после захвата.
- Использован raw CDP PNG1920×1080. Chrome zoom/DPR и device metrics влияли
  на CSS-размеры; это не заявление нативного разрешения или FPS-приёмка.
- Снимки не ретушировались и не проходили через генератор как фон результата.
  Фон служил прикреплённым визуальным контекстом всех трёх генераций.

Три независимых вызова встроенного Image Gen создали только прозрачный UI.
Оригиналы без изменения скопированы в `generated/01.png`–`03.png`; порядок
соответствует показу в чате. Полные запросы — `prompts.json`.

`index.html` — статический просмотрщик двух image-слоёв: неизменный реальный
фон и выбранный прозрачный слой UI. `object-fit:contain` сохраняет пропорции
сгенерированных изображений. Это не построенный игровой интерфейс: кнопки
внутри изображений и шкалы не интерактивны. Работают только переключатели
вариантов и показ исходного фона. Новые зависимости и игровые файлы не менялись.

`previews/01.png`–`03.png` сняты из этого просмотрщика в Chrome1920×1080,
проверены визуально. Дрон не перекрыт панелями. Сравнение RGB центральной
области, включая дрон, записано в `pixel-proof.json`: из423000 пикселей
отличаются9/5/11 соответственно из-за редких пикселей прозрачных UI-слоёв.
Это не ноль и не доказательство тождественности всей композиции: панели
намеренно перекрывают остальную часть кадра. Сам PNG-фон у всех один и тот же.

Числа соответствуют ранее проверенной локальной модели Luma; публичный UI
свежим кадром подтверждает595г,5.6×,около6мин.35мс и28.9Вт·ч не показаны
на старом публичном экране. Заполнение шкал иллюстративное, физика не менялась.
Растровые края/типографика концептов требуют финальной проработки после выбора;
это не готовые компоненты и не утверждённый новый знак PARVOZ.

## Локальное сравнение

Из корня проекта:

```powershell
python -m http.server 2571 --bind 127.0.0.1 --directory docs/ui-research-20261028/realistic
```

`http://127.0.0.1:2571/?option=1` — обычный просмотр; клавиши1/2/3 выбирают
вариант. `&capture=1` скрывает внешнюю полосу сравнения. Проверены переключение
всех вариантов, decode изображений и показ исходника без UI. HTTP200.

После прерывания Chrome перезапущен внешне; старое соединение3 и его вкладки
исчезли. Обнаружен тот же extension/profile на соединении4, доступ заново
проверен реальными переключениями и захватами. Старые overrides относятся к
закрытым вкладкам. В новой вкладке focus/device overrides сброшены; обычный
просмотр оставлен открытым для выбора. Оба окна usage limits прочитаны заново.

Исходники сцены/дрона — Liftoff, LuGus Studios и правообладатели по сохранённой
provenance проекта. Сохраняются прежние условия согласованного теста; новые
права на распространение не утверждаются. Репозиторий остаётся приватным.

Oracle, базы игроков, физика и игровой runtime не обновлялись. Следующий шаг:
выбор/правки визуального направления пользователем, затем план реализации
и одобрение этого плана до изменений в игре.
