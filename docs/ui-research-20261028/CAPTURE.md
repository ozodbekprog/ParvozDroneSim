# Захват и проверка вариантов

28 октября 2026. Это продолжение визуального обсуждения, не реализация в игре.

## Источник

Публичная игра открыта в Chrome и показала `index-OPei9JC_.js`; вход/ангар
работали, но готовый 3D-предпросмотр не появился. Удалены только два CacheStorage
игрового origin, выполнены bypass SW / disabled HTTP cache и reload. Пустой
предпросмотр не использован как фон и не объявлен проверкой внешнего вида.
Точная причина задержки не установлена; диагностика/исправление вне этого этапа.

Поэтому снята **текущая локальная сборка** `index-C6kry7tX.js` на loopback 2572
с отдельной базой. Пользователь был уведомлён об этом до использования кадра.
Исходный код соответствует текущему checkout; за время работы другой чат
сохранил acceptance-инструменты в `02e6f68`, они не включаются в этот UI-пакет.
Чужой acceptance run имеет другой threadId и статус passed, он не возобновлялся.

В новой локальной сессии: RU → готовность → Ангар → Luma 5 → Настроить копию.
Кадр принят после фактического появления модели и `aria-busy=0`. Внутренний
framebuffer до точного raw capture наблюдался 1536×864 при CSS1920×1080/DPR≈0.8.
Для PNG использован временный CDP metrics override и raw capture с результатом
1920×1080. Масштаб Chrome влияет на соотношение CSS и device px: размер PNG
проверен по метаданным, а не принят равным CSS viewport по предположению.
Это реальный рендер текущих ресурсов, **не нативная 1080p/FPS-приёмка**.

UI скрывался временным style только в тестовой вкладке; layout оставался на
месте. Стиль удалён сразу после снимка. Результат не редактировался после
захвата. В исходном кадре нет сгенерированной замены ангара или дрона.

## Отдельный стенд

`127.0.0.1:2571`, свой package/lockfile, Web Awesome Core 3.14.0. Основной
package.json, package-lock и игровые модули не менялись. Модель не рендерится
второй раз: один PNG служит общим фоном, а новый DOM — независимым слоем поверх.
Официальные Button и Details действительно загружаются из установленного
пакета, а не имитируются самодельными элементами с похожими именами.

В Chrome проверены все три направления и сохранены отдельные PNG1920×1080.
Обнаруженное наложение примечания и панели характеристик во втором варианте
исправлено до итогового снимка. Expanded Details имеет ограниченную высоту и
внутреннюю прокрутку; основные действия не сдвигаются. Проверка второго
варианта: высота характеристик 340 CSS design px, scrollHeight482, положение
footer неизменно до/после раскрытия. Вкладки/категории — просмотр состояний,
не реальный editor. Save сообщает «Это макет — игра не изменена».

Стенд позволяет вернуться к чистому исходному фону. Его `currentSrc` сохраняется
при переключении вариантов; naturalWidth/Height1920×1080. Никакие window API
игры, endpoint сохранений или player storage стенд не вызывает.

## Проверка пикселей

Из исходного PNG и каждого итогового снимка прочитана одна область
`left=500, top=300, width=1000, height=620`, охватывающая дрон и рабочий стол.
RGB сравнение даёт **0 различающихся пикселей из 620000** у каждого варианта.
Отчёт — `background-proof.json`. Это подтверждает неизменность открытой области
фона, не сравнение пикселей под перекрывающими её панелями.

## Остальные проверки и границы

- Prototype JS syntax и отдельная Vite production-сборка.
- Итоговый build: JS145.93 kB / gzip37.87 kB, CSS64.30 kB / gzip9.72 kB,
  два локальных WOFF2 суммарно309.42 kB, PNG-фон1528.94 kB. Это размеры этого
  изолированного макета, не прирост игрового runtime и не измерение FPS.
- HTTP200 у макета и фона, загрузка шрифтов локально.
- Метаданные/хеш PNG и отсутствие изменений файлов игры.
- Это desktop canvas для выбора композиции, а не проверка responsive UI всей
  игры, gamepad, WCAG, физики или производительности целевого ноутбука.
- Oracle, production accounts и лимит20 не менялись.

Сервер игры нужен только для съёмки и останавливается после захвата.
Временный style скрытия UI удалён; capture tabs закрыты; focus, device metrics,
network bypass и browser viewport overrides сброшены. Настройки публичной игры
и её данные не менялись, кроме согласованной очистки кэша ресурсов.
Стенд2571 оставлен открытым для выбора; его можно остановить Ctrl+C в собственной
терминальной сессии или запустить снова командой из README.
