# Harborworks — spacious native Blender edition

Harborworks is an original industrial harbour authored in Blender 5.1.0. The spacious baseline was generated by `tools/blender/rebuild_harborworks.py` from the compact pre-expansion package. The current editable source, `content/maps/harborworks/map.blend`, also includes later flight features and the workshop modeled through the open Blender MCP session on **1 October 2026**. Runtime scenery is exported by Blender into `model.glb`; `thumbnail.png` is an actual Blender camera render. Surface images are painted locally in Blender; geometry and textures use no external assets.

## Space and layout

The estate spans **860 × 840 metres**, from X -420 to 440 and Z -420 to 420. The tallest navigation towers reach 49 metres. The original detailed working harbour remains at the centre, expanded **2× horizontally and 1.35× vertically**. Existing workshop interiors, cranes, containers, tanks, boat and quay therefore have much broader flight corridors.

New areas include five western fabrication halls with open ends and wide internal aisles, northern stacked-container logistics yards, a southern tank farm and administrative buildings, an eastern freight-terminal island with maintenance hangar and customs office, additional portal cranes, extended piers, road bridges and prominent navigation towers. Broad roads and uncluttered aprons connect the areas. Modular windows, roof equipment, corrugation, workbenches, task lights, tank ladders, pipework, bollards, fenders and shipping crates provide medium detail at FPV distances.

The original 13-gate Quayside Circuit and 14-gate High Tide Technical courses are retained. Their positions were scaled in the baseline integration pass; the October live workshop pass preserves their IDs and route layout. Native checkpoint empties are organized by track in an authoring collection. The package exporter reads them into race JSON and excludes them from the scenery GLB.

The live pass replaces one generic gate-2 bay with an editable gabled workshop: extruded steel columns, roof trusses, standing-seam slopes, clerestory glazing, open window reveals, gutters and workbench tools. It adds close-flight detail to the established harbour; the surrounding modular buildings, terrain and many simple objects remain part of the scene. See [HARBORWORKS-LIVE-MODELING.md](HARBORWORKS-LIVE-MODELING.md).

## Native editing and delivery

Named collections separate the original centre, terrain, western workshops, northern logistics, eastern terminal, southern refinery, street details, route metadata and preview setup. The new workshop is in **09 Harborworks crafted pilot workshop**. The `.blend` retains individually named modular mesh objects and editable modifiers; the delivery exporter uses temporary material batches with UVs and normals.

The images include base-color and normal textures from `textures/blender-painted/`; the `.blend` packs them and the GLB embeds them. `authoring.json` retains baseline fields such as `collisionBoxes`; the current collider count above comes directly from `collision.json`.

Tiny trim, narrow decorative railings and tool details remain noncolliding. Tank collision still uses conservative square boxes; workshop structures use simplified mesh proxies. Water is static visual scenery without buoyancy or waves. All scenery is static. The original atmosphere and map identity remain; outdoor fog density is 0.0014 and the generic extra ground plane is disabled.

## Regeneration

The generator reproduces the spacious baseline. Running it overwrites the current Harborworks source and removes subsequent live workshop edits and painted materials. Back up the current package first and use an immutable pre-expansion package as input; the already expanded canonical GLB would apply the expansion again. Example from the repository root:

```powershell
& 'D:/Programs/Blender Foundation/Blender 5.1/blender.exe' --background --python tools/blender/rebuild_harborworks.py -- --source data/content-spacious-20260930-230248/content/maps/harborworks --races data/content-spacious-20260930-230248/content/races
```

This rewrites the Harborworks native source, runtime geometry, collision, metadata, atmosphere definition and thumbnail. It does not change race JSON or publish generated delivery assets. For edits to the current live edition, open the saved `.blend` and follow [BLENDER-WORKFLOW.md](BLENDER-WORKFLOW.md). The historical `build_model.py` describes the earlier compact edition.

## Focused validation

The October live MCP session executed the workshop stages, painted PBR images and UVs, rendered the native camera preview, saved the scene and exported the current runtime package. The publication record in `data/live-blender-modeling.json` reports two Harborworks courses and matches the current GLB size.

Historical checks of the spacious box-only baseline do not establish clearance for the present package with added mesh proxies. The live workshop checks inspect new proxy bounds along straight course segments; `live_check.py` examines new proxies near spawn and gate centres. These checks have limited geometric scope. Full gate-volume clearance, controller flight and browser frame rate require separate evaluation.
