# Parvoz Class: локальная ведомость группы

25 октября 2026. Реализация ТЗ-01 из
[предполагаемого ТЗ заказчика](CLASS-CUSTOMER-SPEC-20261025.md).
ТЗ составлено внутри проекта; ТехноСим его не передавал и не согласовывал.
С компанией не велась переписка. Это результат разработки, не подтверждение спроса.

## Что сделано

- В Class добавляется до 20 кодов учеников. Ведомость выбирается по упражнению
  и дате в явно показанном часовом поясе компьютера преподавателя.
- В Start, Class и результатах урока есть выгрузка отчёта преподавателю в JSON.
  В файл попадают только завершённые попытки; пустой отчёт тоже допустим.
- Преподаватель загружает файл в строке выбранного кода. Повторный импорт
  объединяется с прежними попытками, старый файл не стирает более новые записи.
- Для каждого кода показываются статус отчёта, число завершений, время и сбросы
  последней попытки. Отсутствующие показатели показаны прочерком, а не нулём.
- Ведомость сохраняется в браузере отдельно для каждого профиля пилота.
  Есть общий CSV, предупреждение при отказе хранения, подтверждение удаления
  внутри строки и кнопка отмены. Основные тексты переведены на RU/UZ/EN.

## Как проверить вручную

После сборки запустить отдельный локальный сервер:

```powershell
$env:HOST='127.0.0.1'
$env:PORT='2583'
$env:DATA_DIR='C:/DroneLiftoffUz/data/classroom-qa-20261025'
node server/index.js
```

1. Открыть `http://127.0.0.1:2583/?edition=class`, нажать «Играть».
2. Выбрать урок, прокрутить до «Ведомость группы», добавить P01, P02.
3. Открыть Start по ссылке задания. После практики скачать «Отчёт для
   преподавателя (JSON)». Передавать файл преподавателю нужно самостоятельно.
4. В Class нажать «Загрузить отчёт P01», выбрать файл именно этого ученика.
5. Проверить дату и упражнение, скачать «Ведомость (CSV)».

Loopback-адрес доступен только на этом компьютере. Доступ с других компьютеров
требует отдельного тестового развёртывания. Полностью автономный класс без
интернета и общий облачный кабинет этим изменением не реализованы.

## Ограничения и продолжение

Все результаты редактируемые локальные отчёты. Они не подписаны, не подтверждены
сервером и не удостоверяют личность ученика. Учёт незавершённых попыток отсутствует.
Время зависит от часов ученика. Отбор по дате использует зону преподавателя.
Последние 200 завершений на участника могут вытеснить старую историю.
CSV не является резервной копией: хранить исходные JSON для повторного импорта.

На уровне кода и описанных проверок закрыт ТЗ-01. До реального коммерческого пилота
остаются ТЗ-02 (оборудование и преподаватель) и ТЗ-03 (пригодный для поставки
контент и комплект документации). Облачные роли, offline-поставка, редактор курса,
сертификаты и SLA — отдельные неопределённые требования, не выполненные обещания.

Oracle в этой работе **не обновлялся**. Новая версия доступна локально и сохраняется
в приватном GitHub на ветке `codex/demand-pilots`. Production-данные, серверный
допуск 20, существующие карты, физика и права на ресурсы не менялись.
Незавершённые файлы презентаций другого чата не входят в это изменение.
