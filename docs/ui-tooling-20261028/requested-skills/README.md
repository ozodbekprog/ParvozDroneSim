## Проверка и воспроизведение

`render.py` использует Pillow и TTF из указанного каталога:

```powershell
python docs/ui-tooling-20261028/requested-skills/render.py --font-dir PATH_TO_SOURCE_SANS_3_TTF
```

Проверено: формат PNG/размер, все строки внутри канвы, отсутствие пересечений
текстовых bounding boxes, девять расчётных сочетаний контраста, отсутствие
изменений центральной области `[375,320,1340,800]` с дроном. Машинный вывод —
`canvas-checks.json`. Совпадение пикселей этого прямоугольника относится к
Pillow-композиции и исходному PNG; это не FPS или browser-rendering benchmark.

Browser попытка `cua.listTabs({browser:'iab'})` вернула
`Local browser use is disabled in Work settings`. Свежий публичный вход с
очисткой кэша, реальное управление, NVDA, axe, 200% zoom, responsive и браузерный
pixel capture в этом ходе не выполнены. Игровая сборка не запускалась: runtime
не менялся. Один расчёт контраста или картинка не подтверждают приёмку продукта.

После подключения Canva/Figma: проверить новые доступные tools и skills;
сначала выполнить read-only feedback. Для Figma нужен редактируемый UI из
слоёв/компонентов, а не импорт всего макета одной картинкой. Для Canva нужен
реальный design ID; edit применяется к draft с просмотром до сохранения.
Игровая реализация — только после визуального выбора, плана и его одобрения.
