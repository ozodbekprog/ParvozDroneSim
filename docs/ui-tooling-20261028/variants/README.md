# Три композиции ангара с настоящими миниатюрами

Визуальное обсуждение28октября2026. Это просмотрщик, не UI, подключённый к игре.
Верхние панели — три отдельных результата встроенного image_gen.imagegen с
прозрачным фоном. Под ними — один неизменный PNG реальной публичной сцены.
Промпты и точный порядок показа — `prompts.json`. PNG генераций копированы
без ретуши; итоговые композиции сняты из Browser в `previews/`.

Карточки — обычный DOM с настоящими PNG256×144. Пять оригинальных изображений
скопированы из хешированных ресурсов игры; происхождение записано в
`assets/drone-sources.json`. Хеши текущих копий — `image-inventory.json`.
Для Luma5Copy1 показывается базовая Luma5: текущий рендер копии пустой.
Fallback обозначен в alt/title и здесь; точный предпросмотр её деталей не заявлен.

Фон — `assets/hangar.png`, точная копия
`../../ui-research-20261028/realistic/evidence/public-hangar-background.png`.
Метод и источник первоначального публичного захвата сохранены в CAPTURE/README
предыдущего этапа. Его не выдаём за новый повторный захват после установки tools.
Гараж/дроны Liftoff принадлежат LuGus Studios и соответствующим правообладателям;
действует прежнее разрешение на согласованный тест, новые права не заявляются.

Source Sans3, Adobe/PaulD.Hunt, SIL OFL1.1 — существующие локальные шрифты.
Embla Carousel8.6.0, David Jerleke, MIT — единственная новая зависимость
просмотрщика. Лицензии в assets; Web-Awesome-LICENSE.md сохранена как справочная
копия предыдущего пакета, Web Awesome в этой серии не импортируется.

## Запуск

```powershell
npm ci --prefix docs/ui-tooling-20261028/variants --ignore-scripts --no-audit --no-fund
npm run dev --prefix docs/ui-tooling-20261028/variants
```

Loopback2573. `?option=1|2|3`, клавиши1/2/3; `&capture=1` скрывает внешнее
управление сравнением. «Исходный фон» скрывает и UI, и каталог, оставляя исходник.
Клик карточки демонстрирует выделение и сообщает, что сцена/параметры фиксированы.
Все фильтры внутри сцены — визуальные подписи, верхние игровые кнопки растровые.
Полёт, сохранение, фильтрация игрового списка и изменение модели не подключены.
Физические значения прежние; заполнение шкал иллюстративно.

## Проверено и не проверено

- JS syntax, Vite production build и HTTP200. В build включены все3генерации,
  все5миниатюр и шрифты. Это отдельный package/lock, не сборка игры.
- Browser: три переключения, decode всех6миниатюр256×144, читаемость имён,
  показ исходного фона. Состояние — `../browser-check.json`.
- Первый снимок выявил перекрытие каталога и статуса справа; графический слой
  уменьшен пропорционально на5% до финального снимка. Фон не трансформировался
  отдельно от общей канвы. Второй/третий просмотрены целиком, модель открыта.
- PNG1920×1080 сняты raw CDP с явным clip1920×1080. Обходилось несоответствие
  CSS/legacy viewport в IAB при zoom/DPR. Временные overrides сброшены.
- `pixel-proof.json` честно записывает ненулевую разницу центральной области:
  браузерное масштабирование/округление не даёт пиксельного тождества. Это НЕ
  заявление0различий. Сам исходный PNG во всех вариантах один и тот же.
- Канва1920×1080 вписывается целиком с сохранением пропорций. Это не проверка
  responsive-реализации игры, взаимодействия всех компонентов или WCAG/FPS.
- Механический Impeccable detector вернул[] на HTML/CSS/JS; он не проверяет
  растровую типографику и не заменяет визуальную приёмку.

Просмотр оставлен доступным на2573 для выбора. Остановка — Ctrl+C в собственной
сессии dev-сервера. После выбора нужен отдельный одобренный план переноса UI.
