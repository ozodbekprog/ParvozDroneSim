# Происхождение визуальных материалов

Дата: 27 октября 2026. Материалы только для исследования и выбора UI.
Ни один файл этого каталога не подключён к runtime или к публичной сборке.

## evidence/

Автор снимков: агент проекта, захват реальной публичной игры в Chrome через
Computer Use. Источник: https://parvoz-drone-sim.duckdns.org/ . Старт выполнен
с удалением CacheStorage только этого origin, отключением HTTP-кэша вкладки и
обходом service worker. Методика, CSS viewport и границы проверки — в README
и browser-verification. Наличие `1280x720` в имени указывает измеренный CSS
viewport, не размеры PNG. Приёмка производительности здесь не проводилась.

В кадрах есть ресурсы локальных Liftoff-импортов, опубликованных по отдельному
разрешению пользователя для сетевого теста. Авторы исходного контента —
LuGus Studios и правообладатели ресурсов по сохранённой в проекте provenance.
Снимок не превращает эти ресурсы в собственные ассеты PARVOZ и не подтверждает
лицензию на самостоятельную коммерческую раздачу. Сохранять приватность репозитория.

## concepts/01.png, 02.png, 03.png

Созданы встроенным `image_gen.imagegen`, без CLI/API fallback.
Каждый результат — отдельный вызов; номер соответствует порядку показа в чате.
Все три вызова получили **фактический локальный PNG**
`evidence/public-workbench-parts.png` как visual reference. Briefs —
`concepts/briefs.json`, полные prompts — в вызовах инструмента этого чата.

Исходные файлы сохранены инструментом под
`C:/Users/User/.codex/generated_images/01a173d4-8448-7c42-9ee5-d698f6b2d01e/`:

| Файл пакета | Исходный файл |
| --- | --- |
| concepts/01.png | exec-2af9b222-9ff8-4885-b770-a02adc3df046.png |
| concepts/02.png | exec-1c104b7c-2ee1-478d-9489-b7bbe7cc9ccf.png |
| concepts/03.png | exec-0b961426-9191-47bc-960b-34be1475cceb.png |

Задание было 1920×1080; фактически инструмент выдал каждый PNG **1672×941**.
Изображения скопированы без масштабирования или иной обработки. Это варианты
визуального оформления, не скриншоты работающего редизайна. Новые детали
рендера, цифры, значки и wordmark в иллюстрациях не согласованы как игровые
ресурсы. Их нельзя переносить в игру вместо существующих моделей и расчётов.

Размеры, байты и SHA-256 всех PNG записаны в `image-inventory.json`.
Git LFS применён по существующим `.gitattributes`.

## npm-metadata.json

Прочитан публичный официальный npm registry. Поля включают версии, дату
публикации, лицензию, зависимости, repository и registry integrity. Пакеты не
устанавливались в игру. `unpackedBytes` не является browser download size.
