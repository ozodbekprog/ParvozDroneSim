# Публичный браузерный проход

27 октября 2026. Chrome с существующим профилем; origin
`https://parvoz-drone-sim.duckdns.org/`. Это реальные наблюдения UI, не локальная
сборка и не нагрузочное испытание. Исходники игры не изменялись.

## Первый проход

1. Открыта публичная игра. Очищены только её два CacheStorage, HTTP-кэш вкладки
   отключён, service worker обойдён; затем reload. Ненулевые transferSize у JS/CSS
   подтверждены. Точные имена кэшей, версии и размеры — в README.
2. Состояние Ready → Play → главное меню → Hangar. Зафиксировано отсутствие
   визуально читаемых имён карточек при наличии текста в accessibility tree.
   `public-hangar.png` снят во время подготовки моделей: это ограничение кадра,
   а не доказательство отсутствия моделей или измерение времени загрузки.
3. Открыты Workbench Parts, Tuning и модальный Flight performance; сохранены
   отдельные снимки. Выбор деталей, PID и сохранение сборки не выполнялись.
4. Открыты Settings / Controls → Language: положение контейнера изменилось.
   Язык первого прохода был UZ, его значение не менялось.
5. Открыт Graphics; измерен CSS 1280×720 при исходном zoom 80%. Первый screenshot
   Graphics не завершился, поэтому по нему не сделан визуальный вывод.
6. Открыта пустая библиотека Replays. Импорт/экспорт и удаление не выполнялись.

После обновления доступных плагинов прежняя вкладка и соединение Chrome стали
недоступны. Пользователю сообщён разрыв; старые снимки сохранены. Затем Chrome
появился снова. Кэш первого прохода не выдаётся за доказательство второго.

## Второй проход

1. Открыта новая вкладка публичного сайта. В профиле уже выбран RU; язык не
   переключался агентом. Снова удалены только `parvoz-downloaded-assets-v1` и
   `parvoz-encoded-assets-v1`; включены bypass SW / disabled HTTP cache; reload.
2. Ready → Play → Settings → Graphics. Сохранён верх панели при CSS1920×869.
   После override измерены `innerWidth=1280`, `innerHeight=720`, DPR≈0.8.
   Сохранена нижняя часть панели после прокрутки, настройки не изменялись.
   Сильная сторона: подписи и switches в нижней сетке выровнены и доступны.
   Проблемы: fullscreen представлен отдельным switch над подписью, остальные —
   строками; длинные названия в ALL CAPS; одинаково подчёркнуты базовые и
   специальные параметры; английское сообщение fullscreen среди RU.
3. Главное меню → Полёт → Minus Two → Начать свободный полёт. Стартовый экран
   показывал `0.0 / 58.9 MiB · 0 / 13 · 0:00`; это наблюдение интерфейса, не
   замер времени. Первый готовый полёт → Esc → одиночная пауза. Скриншот сохранён.
   Одиночная пауза корректно выделяет Resume, но четыре вторичных действия и
   выход оформлены почти одинаковыми длинными строками.
4. Выйти из полёта → Multiplayer. Наблюдались `0 rooms · 0/20 online`.
   Создана **собственная закрытая** тестовая комната на два места, Minus Two,
   Race, один тестовый guest. Другие игроки не приглашались, код не передавался,
   чат-сообщения не отправлялись. Это проверка UI комнаты, не двухклиентного
   сетевого взаимодействия или ёмкости сервера.
5. Start session → Pause. Раскрыт Room chat. Сохранён снимок
   `public-pause-chat-1280x720.png`. Пустой чат на UZ/RU содержит английское
   `Room chat is empty.`; поле ввода и Send используют всю ширину общей панели.
   Верхние disclosures мелкие относительно кнопок; раскрытие меняет геометрию
   всей панели, сдвигая основные действия. Надпись о продолжении полёта в MP
   присутствует и полезна.
6. Измерены позиции кнопок в том же CSS1280×720:

   | Кнопка | Chat expanded, top CSS px | Chat collapsed, top CSS px | Высота |
   | --- | ---: | ---: | ---: |
   | Продолжить | 414.03125 | 358.875 | 38 |
   | Выйти из полёта | 579.03125 | 523.875 | 38 |

   Сдвиг около **55.2 CSS px**. Это измерение конкретного состояния, не
   предполагаемое поведение из одного CSS-файла. Снимок collapsed не сохранён:
   screenshot API завершился timeout; числа получены из DOM до/после обычного
   клика по disclosure. Expanded и solo PNG получены после `Page.bringToFront`;
   временная проблема захвата не выдана за игровой баг.
7. Выйти из полёта → Multiplayer: снова `0 rooms · 0/20 online`, активного
   тестового полёта и собственного лобби нет. Игровые сообщения не отправлялись,
   настройки сборки не сохранялись и повторы не удалялись.
8. `Network.setCacheDisabled(false)`, `Network.setBypassServiceWorker(false)`,
   `viewport.reset()` выполнены успешно; тестовая вкладка закрыта. Пользовательские
   вкладки Chrome не закрывались. Cleared CacheStorage не восстанавливался:
   ресурсы будут снова кэшироваться при нормальном использовании игры.

## Ограничения

Проверено пустое состояние чата, не длинная история и не переписка нескольких
людей; не проверены NVDA, контроллер/gamepad, узкий мобильный экран, другие
браузеры, фактический контраст и многопользовательская нагрузка. Из overlay FPS
на screenshot нельзя выводить производительность целевого UHD620: качество
Ultra, машина и фокус вкладки отличаются от приёмочных условий. Никакие значения
FPS из этого прохода не объявляются результатом приёмки.

Предложение для обсуждения: стабильное место Resume и выхода; чат — отдельная
область с ограниченной высотой и прокруткой истории; число непрочитанных и
понятный disclosure вместо растягивания всей колонки. Боковая панель, drawer
или соседний раздел выбираются по согласованному визуалу, не автоматически.
