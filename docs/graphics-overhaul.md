# Ironworks / Kestrel — локальный кандидат

Обновлено 2026-10-09. Выбрано оформление **02 — изношенная промзона**. Пользователь отверг двор 48×48 м как слишком маленький. Текущая карта расширена до **300×240 м**, но её внешний вид ещё не принят. **Oracle не обновлён; 60 FPS на UHD 620 не подтверждены.**

## Большая карта

Редактируемый упакованный исходник: `content/maps/ironworks-v2/map.blend`. Четыре новых здания: литейный цех 54×36 м, погрузочный склад 60×24 м, ремонтное депо 24×18 м, диспетчерская башня. Семь зон включают прежний двор, трубопроводный участок и открытое поле полётов. Грунтовый участок — 380×320 м. Авторские Blender-модели кранов, оборудования, бочек, электрических опор и ограждения; авторы, ссылки и CC0 лицензии сохранены в SOURCE.json. Платных покупок и ассетов Liftoff нет.

Full Site Run: **928 м, 29 ворот**, один круг. Новое задание Full Site Inspection, цель 180 секунд. Короткие Loading Run / Loading Hall Inspection сохранены. Старый опубликованный Industrial / Ironworks и его рекорды не менялись.

26 пространственных участков по 32 м, три LOD, один общий GLB. 79 именованных селекторов; GPU instances остаются внутри своих участков. Стандартный instance() переносил геометрию на корень сцены, ломая выборочные LOD; исправлено. Вблизи UV/PBR/нормали, вдали — облегчённая авторская геометрия и запечённые цвета текстур в вершинах. KTX2≤1024, Meshopt. Дороги и грунт образуют непрерывную поверхность без пересекающихся плоскостей. У материала крана исправлен импорт RGB-маски как цвета: используется авторская diffuse-текстура; исправление сохранено в .blend.

Коллизии: 1597 объектов, 11524 архитектурных треугольника; проёмы открыты, стекло и оборудование имеют коллизии. Авторские рамки ворот: видимый и физический проём 2,6×2,2 м, толщина 0,208 м.

## Kestrel

`content/drones/kestrel/kestrel.blend` сохраняет геометрию, UV, материалы и сменные узлы. Источник: [Drone racing — 3D Husky (Kawasalto)](https://sketchfab.com/3d-models/drone-racing-0b416d03688a43239a550d9dad0a6f34), [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Оригинал и сведения о производных сохранены; производные остаются CC BY-SA 4.0. Автор и лицензия видны в ангаре.

Готовые GLB собранного базового дрона: **37780 / 10410 / 2809** треугольников — ангар / Low / дальний вид; невидимые шаблоны исключены. Пять сменных категорий, отдельные оси и крепления во всех LOD. SCOUT/HUNTER отличаются отделкой; большинство форм общие. Двух- и трёхлопастные пропеллеры отличаются также геометрией. Это не десять разных конструкций. Все категории используют общие URL. ID Kestrel, параметры полёта и характеристики деталей сохранены.

## Проверки и оставшаяся приёмка

**169 тестов прошли**, production-сборка прошла. Проверены селекторы и экземпляры LOD, KTX2, размеры ворот и непрерывные выборки всей трассы с радиусом 0,32 м. Короткое задание проверяется реальной SoloSession с подготовленными пересечениями ворот; это не ручной заезд. Смена деталей, цвета, вращение четырёх пропеллеров и переходы LOD проверены в игровом загрузчике. Full Site Run выбран и запущен через настоящее игровое меню с отдельной тестовой базой; HUD показал 1 круг / 29 ворот. Полный ручной заезд не выполнен.

Просмотр: `http://127.0.0.1:2570/editor/ironworks-v2.html`; дрон: `/editor/kestrel-modular.html`. Настоящий World, Low, framebuffer 1280×720, адаптация выключена. Осмотр маршрута движет камеру без физики и не считается замером FPS.

Требуются художественная приёмка и целевой i5/UHD 620: три прохода по три минуты после прогрева, 1/8 участников, WebGPU/WebGL2, настоящая физика. Записывать framebuffer, времена кадров, 1% low, треугольники, calls и память текстур. F4 — запись, F6 — JSON. Цель: медиана≤16,7 мс, 1% low≥50 FPS. GTX 1650 её не подтверждает. Ранее WebGL2 имел низкую частоту кадров даже в пустой сцене; причина не определена, backend по FPS не принят.

## Сборка

Blender: BLENDER_PATH, по умолчанию `D:/Programs/Blender Foundation/Blender 5.1/blender.exe`. Официальный KTX: `tools/bin/ktx/portable/bin`. Команды: `npm run art:ironworks:build`, `npm run art:ironworks:check`, `npm run art:kestrel:modular`, `npm run art:kestrel:modular:check`.

IRONWORKS_OUTPUT_DIR позволяет собирать промежуточные файлы на другом диске; локально `D:/DroneLiftoffArtBuild/ironworks-site`. Готовые GLB и .blend возвращаются в content/. `--optimize-only` обрабатывает raw GLB; `--prepared-only` проверяет и интегрирует сжатые файлы. export_ironworks_site.py повторяет экспорт сохранённой сцены. Не выбранные clean/evening .blend сохранены с проверкой SHA-256 в `D:/DroneLiftoffArtBuild/review-sources/`; выбранный worn остаётся в проекте. Исходники не утрачены.
