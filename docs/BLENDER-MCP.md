# Blender MCP

Установлен `mcp-for-blender==2.1.3` из проекта
[MCP for Blender](https://github.com/ahujasid/mcp-for-blender).
Дополнение включено в Blender 5.1, сервер зарегистрирован в
`C:/Users/User/.codex/config.toml` как `blender`.

## Использование

1. Полностью закройте и снова откройте Codex, чтобы он загрузил новые MCP-инструменты.
2. Откройте Blender и нужный `content/maps/<id>/map.blend`.
3. Дополнение автоматически запускает локальное подключение на `127.0.0.1:9876`.
   Проверить его можно в боковой панели 3D Viewport: **N → MCP for Blender**.
   Если сервер остановлен, нажмите **Start MCP Server**.
4. После редактирования сохраните `.blend` и опубликуйте карту обычной командой:

```powershell
npm run content:blender -- --map harborworks --publish
```

MCP управляет открытой сценой Blender. Сохранение сцены и публикация в игру
остаются отдельными действиями. Не открывайте несколько экземпляров Blender
на одном MCP-порту.
